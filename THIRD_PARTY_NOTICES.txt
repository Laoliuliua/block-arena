Minecraft Java Edition 1.20.4 item textures

The snowball, stone sword, sweet berries, leather boots, baked potato, loaded
crossbows, firework rocket and arrow use item sprites from Minecraft Java
Edition 1.20.4 (Mojang Studios / Microsoft). The game stores lossless indexed
pixels in ice-art.js for offline rendering. Leather boots combine the
base layer with the default leather dye colour #A06540 and the overlay.

The poison and harming liquid colours follow the supplied reference chart.
The two ribbon colours distinguish Sharpness and Power as in the reference clip.
The TNT front face is sampled from the supplied reference image; the ravine
tile art and layout are based on the supplied video.

Sound effects: Minecraft Java Edition 1.20.4, Mojang Studios / Microsoft.
The local Ogg Vorbis files in assets/audio were retrieved unchanged from
the official Minecraft resource CDN, https://resources.download.minecraft.net/.
See assets/audio/sources.json for the Mojang version manifest, asset index,
event definitions, original asset keys, and individual SHA-1 hashes.

The Vindicator portrait, Totem of Undying and fire charge sprites are sampled
from the three player-supplied reference images. The iron axe uses the Java
1.20.4 item texture iron_axe.png from the same texture mirror above (Git blob
43e742c28f79eff61144a25b07d9207da6f17d83). Vindicator hurt, totem activation,
and blaze shooting are their corresponding Minecraft events. The summoned axe
uses iron equipment and melee hit sounds; ignition uses the flint and steel sound.

The Witch portrait and the red drinking potion follow the player-supplied
Witch and potion reference images. The Witch's hurt, drink and throw recordings
are Minecraft Java 1.20.4 Witch events. Brewing uses the vanilla bottle-fill
sound. Source paths and checksums are included in assets/audio/sources.json.
